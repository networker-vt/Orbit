# Accessibility (Allda v2.8.1)

Allda is a mobile-first PWA. Choices in this release:

- **Skip link** to `#main-content` on every screen.
- **Focus**: `:focus-visible` rings use the section `data-theme` accent. Mouse clicks do not leave a persistent outline (`:focus:not(:focus-visible)`).
- **Tap targets**: nav, stars, Interesse, file pickers, and the button system (`primary` / outlined `secondary` / `tonal`) are at least 44×44px (`tap-target` / `min-h-11`). Press scale is off under `prefers-reduced-motion`.
- **Motion**: existing animations already wrap in `prefers-reduced-motion: reduce`. Robot tap bounce/blink is static under reduced motion; the one question still appears.
- **Contrast**: light parchment default (`#faf8f5` / ink `#1c1917`); optional dark toggle. Optional Ideen-Box contrast tweak (`html.tweak-contrast`) still available.
- **Semantics**: one `h1` per page, section `h2`s, `nav aria-label="Primary"`, `main` landmark. Robot is a button with `aria-expanded`.
- **Language**: `document.documentElement.lang` follows the Mein Bereich switcher (DE/EN; ES/FR/PL stubs set `lang` but copy falls back to EN).
- **TTS**: Web Speech API “read aloud” on Home hero, Treffer job cards, listing detail, Photo, Interview, Erfahrungen. Users can stop. Unsupported browsers get a visually hidden note.
- **Keyboard**: Treffer deck — ArrowLeft skip, ArrowRight/Enter Interesse. Dialogs (Create sheet) close with Escape.
- **Forms**: labels on inputs; star ratings as `radiogroup`; file inputs have visible triggers.
- **Honest demos**: photo “vision”, video call, and credits are labelled as stubs so assistive tech is not implying live payments or WebRTC.

- **Parental gate**: Allda Kids PIN dialog is labelled (`role="dialog"`). PIN setup happens before kid UI. Age-band picker buttons are outlined secondary, not text links.
- **Orbi trip cards**: each card is one large tap target (not a filled primary). Confirmation sheet is `role="dialog"`; only **Bestätigen** books a demo stub. Voice select is a whitelist (`1/2/3`, `eins/zwei/drei`, `Option eins`). Kids mode hides adult travel booking.
